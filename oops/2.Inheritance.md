## Challenge 1: Normal Inheritance (Single Inheritance)

**Question:**

Create a parent class `Vehicle` with the following:

- Attributes: `brand`, `model`
- Method: `display()` → prints brand and model

Create a child class `Car` that inherits from `Vehicle` and has:

- Extra attribute: `fuel_type`
- Method: `display()` → prints brand, model, and fuel type (Method Overriding)

Create an object of `Car` and call the `display()` method.

**Code:**

```python
class Vehicle:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def display(self):
        print(f"Brand: {self.brand}, Model: {self.model}")


class Car(Vehicle):
    def __init__(self, brand, model, fuel_type):
        super().__init__(brand, model)
        self.fuel_type = fuel_type

    def display(self):
        print(f"Brand: {self.brand}, Model: {self.model}, Fuel Type: {self.fuel_type}")


# Creating object
c = Car("Toyota", "Innova", "Diesel")
c.display()
```

**Expected Output:**

```text
Brand: Toyota, Model: Innova, Fuel Type: Diesel
```

## Challenge 2: Types of Inheritance

**Question:**

Demonstrate the following types of inheritance using suitable classes:

1. Single Inheritance
2. Multiple Inheritance
3. Multilevel Inheritance
4. Hierarchical Inheritance

---

### 1. Single Inheritance

**Code:**

```python
class Father:
    def show_father(self):
        print("This is Father class")


class Son(Father):
    def show_son(self):
        print("This is Son class")


s = Son()
s.show_father()
s.show_son()
```

**Output:**

```text
This is Father class
This is Son class
```

---

### 2. Multiple Inheritance

**Code:**

```python
class Father:
    def show_father(self):
        print("This is Father class")


class Mother:
    def show_mother(self):
        print("This is Mother class")


class Child(Father, Mother):
    def show_child(self):
        print("This is Child class")


c = Child()
c.show_father()
c.show_mother()
c.show_child()
```

**Output:**

```text
This is Father class
This is Mother class
This is Child class
```

---

### 3. Multilevel Inheritance

**Code:**

```python
class Grandfather:
    def show_grandfather(self):
        print("This is Grandfather class")


class Father(Grandfather):
    def show_father(self):
        print("This is Father class")


class Son(Father):
    def show_son(self):
        print("This is Son class")


s = Son()
s.show_grandfather()
s.show_father()
s.show_son()
```

**Output:**

```text
This is Grandfather class
This is Father class
This is Son class
```

---

### 4. Hierarchical Inheritance

**Code:**

```python
class Father:
    def show_father(self):
        print("This is Father class")


class Son(Father):
    def show_son(self):
        print("This is Son class")


class Daughter(Father):
    def show_daughter(self):
        print("This is Daughter class")


s = Son()
d = Daughter()

s.show_father()
s.show_son()

d.show_father()
d.show_daughter()
```

**Output:**

```text
This is Father class
This is Son class
This is Father class
This is Daughter class
```

## Summary: Types of Inheritance

| Type | Description |
|---|---|
| Single Inheritance | One child class inherits from one parent class. |
| Multiple Inheritance | One child class inherits from two or more parent classes. |
| Multilevel Inheritance | A class inherits from another child class, forming a chain. |
| Hierarchical Inheritance | Multiple child classes inherit from the same parent class. |

### Quick Revision

- **Single:** One parent → One child
- **Multiple:** Multiple parents → One child
- **Multilevel:** Grandparent → Parent → Child
- **Hierarchical:** One parent → Multiple children
