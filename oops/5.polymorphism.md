## Challenge 1: Method Overriding (Basic Polymorphism)

**Question:**

Create a parent class `Animal` with a method `sound()`.

Create three child classes:

- `Dog` → overrides `sound()` and prints `"Dog barks"`
- `Cat` → overrides `sound()` and prints `"Cat meows"`
- `Cow` → overrides `sound()` and prints `"Cow moos"`

Create a function `make_sound(animal)` that calls the `sound()` method.

Pass different animal objects to the same function and observe polymorphism.

### Code:

```python
class Animal:
    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):
    def sound(self):
        print("Dog barks")


class Cat(Animal):
    def sound(self):
        print("Cat meows")


class Cow(Animal):
    def sound(self):
        print("Cow moos")


def make_sound(animal):
    animal.sound()


# Creating objects
d = Dog()
c = Cat()
cw = Cow()

make_sound(d)
make_sound(c)
make_sound(cw)
```

### Expected Output:

```text
Dog barks
Cat meows
Cow moos
```

## Challenge 2: Polymorphism with Shapes

**Question:**

Create a parent class `Shape` with a method `area()`.

Create two child classes:

- `Rectangle` → calculates area as length * breadth
- `Circle` → calculates area as 3.14 * radius * radius

Create a function `print_area(shape)` that calls the `area()` method.

Pass different shape objects and observe polymorphism.

### Code:

```python
class Shape:
    def area(self):
        pass


class Rectangle(Shape):
    def __init__(self, length, breadth):
        self.length = length
        self.breadth = breadth

    def area(self):
        return self.length * self.breadth


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius * self.radius


def print_area(shape):
    print("Area:", shape.area())


# Creating objects
r = Rectangle(10, 5)
c = Circle(7)

print_area(r)
print_area(c)
```

### Expected Output:

```text
Area: 50
Area: 153.86
```

## Challenge 3: Polymorphism with + Operator Concept + Method Overriding

**Question:**

Create a class `Calculator` with a method `add()`.

Create two child classes:

- `NumberAdd` → adds two numbers
- `StringAdd` → joins two strings

Demonstrate polymorphism by calling the same method name `add()` with different behaviors.

### Code:

```python
class Calculator:
    def add(self, a, b):
        pass


class NumberAdd(Calculator):
    def add(self, a, b):
        return a + b


class StringAdd(Calculator):
    def add(self, a, b):
        return a + b


# Creating objects
num = NumberAdd()
text = StringAdd()

print("Number Addition:", num.add(10, 20))
print("String Addition:", text.add("Hello ", "World"))
```

### Expected Output:

```text
Number Addition: 30
String Addition: Hello World
```
