## Challenge 1: Class & Object

**Question:**  
Create a class `Student` with the following:  
- Attributes: `name`, `roll_no`, `marks`  
- Methods:  
  - `display()` → shows student details  
  - `is_pass()` → returns `"Pass"` if marks ≥ 40, otherwise `"Fail"`  

Create 3 student objects and display their details + result.

**Code:**

```python
class Student:
    def __init__(self, name, roll_no, marks):
        self.name = name
        self.roll_no = roll_no
        self.marks = marks

    def display(self):
        print(f"Name: {self.name}, Roll No: {self.roll_no}, Marks: {self.marks}")

    def is_pass(self):
        if self.marks >= 40:
            return "Pass"
        else:
            return "Fail"


# Creating objects
s1 = Student("Rahul", 101, 78)
s2 = Student("Priya", 102, 35)
s3 = Student("Aarav", 103, 92)

s1.display()
print("Result:", s1.is_pass())
print()

s2.display()
print("Result:", s2.is_pass())
print()

s3.display()
print("Result:", s3.is_pass())


Expected Output:textName: Rahul, Roll No: 101, Marks: 78
Result: Pass

Name: Priya, Roll No: 102, Marks: 35
Result: Fail

Name: Aarav, Roll No: 103, Marks: 92
Result: Pass
